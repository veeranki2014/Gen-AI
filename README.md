## What is a Library?

1) Collection of packages
Example : Numpy Library
Contains
		- Linear Algebra
		- Random
		- Statistics
		- Matrix

** package means collection of modules.
** Module means python file.

### Types of Python Libraries
	
1) Standard Libraries (Already available, we no need to install)

		- math
		- random
		- datetime
		- os
		- sys
		- json

2) Third Party Libraries (we need to install)

		- numpy
		- pandas
		- matplotlib
		- flask
		- django
		- tensorflow
		- fast-api
		- scikit-learn
		- streamlit

Using : using pip we can install third party libraries.

Note: Better to use virtual environment to install project specific libraries.		

### Numpy : 

		- Purpose : Numerical Computing
		- Used For : Arrays, Matrix Operations, Linear Algebra
		- Projects: AI, ML, Scientific Computing

### Pandas : 

		- Purpose : Data Analysis
		- Used For : Reading CSV/Excel, Data Cleaning, Data Manipulation
		- Projects : Data Science, Business Intelligence		

### Matplotlib :

		- Purpose : Data Visualization
		- Used For : Line, Bar, Pie, Graph, Scatter Charts		
		- Projects : Reports, Dashboards

## Flask :
		
		- Purpose : Web Framework
		- Used For : REST APIs, Small Web applications
		- Projects : Backend services, Microservices

## Django :

		- Purpose : Fullstack Web Framework
		- Used For : Large Scale Enterprise web applications
		- Projects : ECommcer, ERP, CRM				

## Scikit-Learn : 

		- Purpose : Machine Learning
		- Used For : Classification, Regression, Clusttering
		- Projects : Predication Systems, Recommendation Systems		

## TensorFlow :

		- Purpose : Deep Learning
		- Used For : Neural Networks, Computer Vision, NLP
		- Projects : Image Recognization

## FAST-API :

		- Purpose : High Performance API framework
		- Used For : REST APIs for AI/ML/GEN AI/Agentic AI projects
		- Projects : Backend REST APIs

## Streamlit :

		- Purpose : Web Apps for Data Science
		- Used For : Build interactive Dashboards
		- Projects : AI Chatbot demos, data Visualization

## Hugging Face :

		- Purpose : AI Model hub
		- Used For : LLMs, Text generation, image genration, AI model deployment
		- Projects : ChatGPT-Like application, AI Assistants, Translation systems
